# Log mill

A single page that plans boards cut from one elliptical log. Enter the diameter across, the diameter vertical, the saw kerf, and the thickness, width, and quantity of each board you want. Requested sizes go in first. Leftover wood is filled with other common sizes. The layout is a practical search, not a proven optimum.

Every cut takes a kerf, including the outer faces, and that kerf band has to lie inside the log.
